# Animal-Charity-Database

## Project Overview

This project involved designing and implementing a relational database for an animal charity using MySQL and phpMyAdmin.
The database was designed to manage animal records, adoptions, medical information, donations, volunteers, and fundraising campaigns.

## Technologies Used

* MySQL
* phpMyAdmin
* SQL
* Entity Relationship Modelling (ERD/EERD)
